Farm Settings update (13 November 2026)
First-time visitors start with no crops or animals selected.
Independent Select All / Deselect All checkboxes for crops and animals.
Selections are saved in the browser and persist between visits.
Reset Farm Settings clears both lists but preserves the calendar and event history.
Specific crop/animal events remain filtered by selected types; general events are unaffected.
Note: visitors with existing saved selections keep them until they use Reset Farm Settings.
